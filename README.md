# Computer Vision - Assignment 1

Introduction to Computer Vision (83551), Bar-Ilan University.

## Contents
| Question | Notebook | Code |
|---|---|---|
| 1. k-Nearest Neighbor | `knn.ipynb` | `icv83551/classifiers/k_nearest_neighbor.py` |
| 2. Softmax classifier | `softmax.ipynb` | `icv83551/classifiers/softmax.py`, `linear_classifier.py` |

| 4. Image features | `features.ipynb` | |
| 5. Fully connected networks | `FullyConnectedNets.ipynb` | `icv83551/optim.py` |

## How to run
1. Install: `pip install numpy matplotlib scipy jupyter imageio six future`
2. Download CIFAR-10: `cd icv83551/datasets && bash get_datasets.sh`
3. Open the notebooks from this folder and run the cells in order
   (when running locally, skip the first cell, which is for Google Colab).
